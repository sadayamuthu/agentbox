## Wanted

Airlock has one maintainer, and wants more, especially from organizations
not already represented. Areas where help would make the biggest difference:

- the Firecracker backend and workspace snapshots,
- the WASM backend and macOS support,
- policy presets for common package managers,
- a public test set of malicious packages.

If you're interested, start with an issue labelled `good first issue` or
`help wanted`, or open an issue to say what you'd like to work on.
